## 如何使用

- 从今日榜单选择感兴趣的 Skill。
- 打开“原始 Skill”查看作者说明与安装步骤。
- 安装前检查账号、费用、文件访问和网络权限。
- “值得试用”不代表已经完成独立安全审计。

## 如何投稿

使用 [Skill 投稿 Issue](../../issues/new?template=submit-skill.yml) 推荐项目。投稿不会自动上榜，系统会检查来源、可安装性、普通用户适配度和权限披露。
